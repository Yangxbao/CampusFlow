## 使用建议

1. **顺序学习**：day 编号即依赖顺序，跨阶段跳跃会缺前置概念；
2. **每天三个固定动作**：读文件 → 跑实验/命令 → 回答面试题（口头，不是默写）；
3. **每周日晚（day07/14/21/28 尾部）做错题回收**：讲不清的知识点标注回炉；
4. **两个实验周**（day23-26）以 `backend/concurrency-lab`、`backend/jvm-lab` 的 lab docs 为主教材，
   本目录只做导航与自检；
5. day30 之前把 `docs/learning/14_项目面试题与参考回答.md` 至少口头过两遍。
